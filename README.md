# Desktop Buddy

Desktop Buddy is a customizable 2D pixel-art desktop companion built with [Godot](https://godotengine.org/) and C#.

The project is designed to live alongside your desktop and taskbar, providing an interactive companion that can gradually evolve with features such as animations, interactions, personality, AI, notifications, and more.

The project is currently under active development, with Windows as the primary target and Linux support planned.

## Why C#?

Desktop Buddy was originally prototyped using GDScript. As the project grew, the codebase became difficult to maintain and scale.

This version is being rebuilt from the ground up using C#, with a stronger focus on:

- Clean and maintainable code
- Scalable architecture
- Modular systems
- Better separation of responsibilities
- Easier long-term development

C# is also the primary programming language I'm most comfortable with, making it a natural choice for the project.
